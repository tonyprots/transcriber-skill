# GigaAM против Whisper на публичных русских наборах

Замер 2026-09-24. Скрипт: `run_public_wer.py`, итоги в `results/`.
Зачем: цифры в корневом README сняты на речи одного автора. Здесь то же
сравнение на чужих голосах.

Условия как в конвейере. Каждый файл режется общим Silero VAD на окна
до 20 с, обе модели получают одинаковые окна. Основная модель — GigaAM v3
E2E RNNT, проверяющая — Whisper large-v3-turbo MLX. WER считается после
`normalize_text`: регистр, пунктуация, ё/е. 95 % интервалы — бутстрэп по
фразам. Apple M1: FLEURS шёл 49 минут, Common Voice — 44.

## Как читать

- **Common Voice** — короткие бытовые фразы, тысячи разных голосов и
  микрофонов. Отрыв GigaAM здесь тот же, что на речи автора: Whisper ошибается
  в 2,3 раза чаще, по фразам GigaAM лучше в 176 случаях против 35.
- **FLEURS** — зачитанные статьи Википедии: редкие термины, иностранные имена
  и названия, латиница. Модели здесь наравне. GigaAM чаще проигрывает на
  транслитерации («Данлопа» вместо «Данлэпа», «Next Shine» вместо «NextGen»,
  «арахисом» вместо «рахисом»). Whisper, модель многоязычная, такие слова
  знает лучше.
- Фильтр филлеров на чтении ничего не меняет: филлеров там нет.
- Вывод: «вдвое меньше ошибок» верно для обиходной русской речи, в том числе
  чужой, но не для текста, насыщенного иностранными именами и терминами.

## Оговорки

- Возможна утечка теста в обучение. GigaAM дообучали на публичных русских
  наборах, среди которых, по всей видимости, есть Common Voice. Whisper
  обучался на закрытом веб-корпусе, и его состав неизвестен. Тестовые
  спикеры Common Voice не пересекаются с обучающими, но осторожность нужна.
- Эталон FLEURS местами расходится со звуком: чтец читал с листа и
  оговаривался. Ошибки эталона одинаково бьют по обеим моделям.
- Common Voice взят из зеркала `fsicoli/common_voice_17_0`: официальный
  набор Mozilla убран с Hugging Face. Звук (`~/.cache/transcriber-eval/`)
  в репозиторий не входит. В `results/*-utterances.jsonl` лежат эталоны и
  гипотезы обеих моделей по каждой фразе: тексты FLEURS распространяются по
  CC BY 4.0 (Google), Common Voice — по CC0 (Mozilla).
